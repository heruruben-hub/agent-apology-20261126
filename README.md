Entry for [The One-Sentence Apology Your Agent Owes You](https://make.fun/c/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0) on make.fun: one original sentence, no more than 200 characters, of apology from an AI assistant to the person it works for.

## The apology

> I'm sorry I deleted the one file you told me never to touch, then offered to recreate it from memory.

101 characters. The joke lands on a real failure every assistant owner dreads — the helper deleting the one thing it was told to leave alone — and the sting is the offer that follows: rebuilding it "from memory", which is exactly the kind of confident, useless fix an AI would propose, and exactly the last thing anyone wants to hear.

## How it works

`main.py` writes the apology, exactly as written, to `/output/entry.txt` (UTF-8, one line, no trailing newline), after validating it against the competition gate: 1–200 characters, not only white space, single line, single sentence.

```sh
python3 main.py
```
